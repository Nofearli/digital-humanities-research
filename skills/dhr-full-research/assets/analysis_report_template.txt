==================================================
一、研究问题与研究设计
==================================================
1. 研究问题（RQ，须与后文分析章节一一对应）
   RQ1：评论集中讨论哪些主题           → 第三节 主题发现
   RQ2：正面/中性/负面情感如何分布     → 第四节 情感结构
   RQ3：不同主题的情感构成是否有差异   → 第四节 主题×情感交叉
   RQ4：哪些概念处于语义网络中心       → 第五节 语义网络
2. 设计说明：为什么用这三个方法（解释动机，不只陈述做法）
3. 样本来源：入选视频数、评论数
4. 伦理声明：采集不保留评论者显示名、头像、频道链接；分析只用匿名 ID、时间、互动量、正文
5. 定位声明：样本适合观察什么、不等同于什么、不能推断什么

==================================================
二、数据处理与方法
==================================================
1. 文本清洗规则（写具体数字，不写"进行了必要的清洗"）
   - 删除空白文本 / 少于 N 个字符 / 纯链接 / 纯符号数字 / 规范化重复
2. 语种识别
   - 模型：fastText（lid.176.bin）
   - 阈值：置信度 ≥ 0.80
   - 未通过者的处理：仅记录匿名 ID、语言、置信度、排除原因，不保留正文
3. 处理漏斗（三级数量，逐级递减）
   原始评论 X 条 → 文本清洗后 Y 条 → 正式语料 Z 条
4. 主题建模
   - 句向量模型：{embedding_model}
   - 降维 / 聚类：{umap 参数} / {hdbscan 或 kmeans 参数}
   - 关键词提取方式
   - 停用词处理（含领域泛词与国家地区词的分别处理说明）
   - ★ 主题命名的性质声明："主题命名不是模型预设分类，而是研究者结合主题规模、
     关键词和匿名代表性短引文进行的解释。"
5. 情感分析
   - 主模型：{model}（三分类 / 二分类+阈值转三类）
   - 对照方法：{vader 或 snownlp}
   - ★ 若为二分类转三类，必须写明："中性类别来自概率区间策略，而非独立训练的类别。"
6. 语义网络
   - 词性过滤范围、窗口大小、节点/边保留上限、社群算法
7. 可复现性
   - 随机种子、缓存位置、原始数据哈希校验机制

==================================================
1. 总体陈述：识别出 N 个非离群主题；另有 M 条归入离群/混合组，不强行解释
2. 图：主题规模（fig_02） + 图：主题空间投影（fig_03）
3. 表：主题概览（编号 / 评论数 / 解释性主题名 / 模型关键词标签）
4. 逐主题展开（每个主题一段）：
   - 规模与占比
   - 含义解释
   - 匿名短引文："……"
★ 引文须人工核对：读得通、能支撑该主题名、不含用户名

==================================================
四、情感结构及其主题差异（RQ2、RQ3）
==================================================
1. 总体分布（绝对数与占比都要给）
   正面 X 条（A%）、中性 Y 条（B%）、负面 Z 条（C%）
2. 立即加限定：正面居首说明什么；中性与负面合计说明什么
3. 方法一致率：与对照方法的逐条一致率为 D%
   - 说明其水平意味着什么
   - ★ 声明："本文将情感结果理解为分布性指标，而非对单条评论的绝对判定。"
4. 图：情感分布（fig_04） + 图：月度情感占比（fig_05）
   ★ 月度数据免责声明："各月样本量和视频来源不同，不据此作趋势或因果推断。"
5. 内容词：正面高权重词 / 负面高权重词（列出）
6. 图：正负面词云（fig_06 ×2）
7. 主题×情感交叉
   ★ 强调："展示的是主题内部的情感构成（行内占比），而非主题之间的绝对评论量差异。"
   ★ 关联性声明："主题来自无监督聚类且各主题样本量不同，该图为描述性关联，非显著性检验或因果结论。"
8. 图：主题情感热力图（fig_09）

==================================================
五、语义网络（RQ4）
==================================================
1. 结构规模：N 个节点、M 条边、K 个概念社群
2. 中心概念：加权度最高的若干词
3. 解释连接：每个中心词连接了哪些话题（不要只复述图）
   ★ 因果免责声明："网络中的边表示评论中词语在局部语境内共同出现的倾向，
      不表示概念之间具有因果方向。"
4. 图：语义共现网络（fig_07） + 图：中心性排行（fig_08）
5. 表：核心概念（概念 / 文档频次 / 加权度 / 介数中心性）

==================================================
六、讨论
==================================================
1. 三套结果的互证关系："主题模型回答'谈什么'，情感分类回答'以何种态度谈'，
   网络分析回答'概念如何联结'。"
2. 分条展开发现（第一、第二、第三……），每条都基于前文数据，不引入新数据
3. 解释与结论分开表述："……并不能直接证明……，却说明……"

==================================================
七、局限与结论
==================================================
局限（分条，每条具体 + 给出应对方向）：
  1. 样本范围：来自筛选后的 N 条视频及可获取的最新公开顶层评论，不能代表全量
  2. 数据处理损失：语种阈值与清洗会排除混合语、极短评论、非标准拼写
  3. 模型不确定性：主题数、聚类边界、自动情感分类均受参数与语境影响
  4. 工具性质：词云与共现网络是描述性工具，不作因果机制或人口属性推断
  应对方向：扩大视频样本、引入人工编码、跨平台语料、对讽刺与文化典故人工复核

结论（独立成段，回到研究设计层面，不重复摘要）
