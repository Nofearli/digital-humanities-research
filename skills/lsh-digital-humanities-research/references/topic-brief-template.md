# 参考资料：《调研主题单》模板与配置方法

> 用法：WorkBuddy 把下面的问题逐条念给用户，用户回答后原样记录，填入"主题单示例"。
> 用户不确定的地方给建议选项，但最终由用户拍板，不得替用户编造。

## 一、逐条问用户（6 问）

1. **想调研什么？**（一句话，如"《哪吒之魔童闹海》在海外观众中的口碑"）
2. **这个对象有哪些名字？** 中文别名、英文译名各列几个（用于把无关视频过滤掉，如 `哪吒2`、`魔童闹海`、`Ne Zha 2`、`Nezha 2`）。
3. **想抓什么类型的内容？** 默认"影评 / 解析 / 反应 / 观后感"，对应检索词和标题过滤；用户也可改为开箱、教程、新闻评论等。
4. **哪些内容一定不要？** 默认排除：预告片、片段、官方宣传、音乐视频；再问一句有没有"容易撞名的其他作品"（如哪吒2要排除"封神"相关，避免数据串味）。
5. **要哪些语言、什么时间范围？** 默认中文 + 英文双语，起始时间默认 2025-01-01（或影片上映日），截止"今天"。
6. **采集多少？** 默认值：每语言 15 个视频、每视频最多 1,000 条评论。用户想少一点（省时间）就调小，想更全面就调大（注意 API 配额）。

## 二、主题单模板（回答后长这样）

```text
【调研主题】哪吒之魔童闹海海外评论
【主题 slug】nezha2-newrun
【别名】中文：哪吒之魔童闹海、哪吒2、哪吒 2、魔童闹海
       英文：Ne Zha 2、Nezha 2、Ne Zha II
【内容类型】影评 / 解析 / 观后感 / 反应 / 解说
       （检索词与标题过滤词：影评、解析、观后感、反应、解说；review、reaction、analysis、recap）
【排除】预告、片段、官方宣传、音乐视频；封神 / fengshen / creation of the gods
【语言】中文 zh + 英文 en
【时间范围】2025-01-01 至 今天
【采集数量】每语言 15 个视频；每视频最多 1,000 条顶层评论
【输出目录】<你的项目文件夹>\nezha2-newrun_youtube_20261012
【报告文件名】哪吒2海外评论_调研报告_20261012.txt
```

## 三、slug 命名规则

- 只用**小写字母、数字、下划线**，如 `nezha2`、`fengshen`、`blackmyth_wukong`；
- 同一个主题再次采集时用新 slug 或直接指定新 `--output-dir`，不要覆盖旧数据。

## 四、把主题单翻译成 `pachong.py` 配置

`pachong.py` 顶部的 `TOPICS` 字典是"主题配置表"。流程：

1. **先查重**：若用户要的主题已存在（脚本可能内置示例主题），直接 `--topic <slug>` 复用，跳到第五步。
2. **新增主题**：仿照现有条目，把主题单逐项填进 `Topic(...)`：

```python
"nezha2_newrun": Topic(
    slug="nezha2_newrun",
    title="用户填写的主题名",
    published_after="2025-01-01T00:00:00Z",          # 时间起点，来自主题单
    language_queries={
        "zh": ["哪吒之魔童闹海 影评", "哪吒2 影评"],   # 每种语言 3~4 个检索词
        "en": ["Ne Zha 2 review", "Ne Zha 2 reaction"],
    },
    inclusion_terms={                                  # 标题/简介必须含其中至少一个
        "zh": ("影评", "影評", "评价", "評價", "解析", "观后感", "觀後感", "反应", "反應", "解说", "解說", "讲解", "講解"),
        "en": ("review", "reaction", "analysis", "ending explained", "thoughts", "explained", "recap"),
    },
    subject_terms=("哪吒之魔童闹海", "哪吒2", "ne zha 2", "nezha 2"),  # 对象别名，全部小写亦可
    per_language=15,                                   # 来自主题单第 6 问
),
```

3. **改动注意**：只能往 `TOPICS` 里新增键，不改动已有主题的字段；保存文件后用 `python -m unittest -v` 跑一遍离线自测（不联网、不耗配额），全绿再进入采集。
4. **dry-run 验证**：`python pachong.py --topic nezha2_newrun --dry-run`，打开 `candidates.csv` 人工核对：是否混入预告/官方/撞名内容，数量是否合理。不达标就回到主题单修订检索词或排除词。
5. **正式采集与后续**：回到 SKILL.md 的 Step 4～6 继续执行。

## 五、常见主题设计错误

- 别名太少 → 候选视频被 `subject_terms` 误杀，最终选不满视频；解法：补齐中英文及大小写变体。
- 检索词太窄 → 搜索结果不足，日志出现 `shortfall`；解法：增加同义检索词，而不是放宽排除规则。
- 排除词写到 inclusion 里（如把"预告"当内容类型）→ 结果全是要排除的东西；解法：排除词只放通用排除逻辑或主题级排除，不进 inclusion。

## 六、输出目录与命名

- 默认输出目录由脚本自动生成为 `<slug>_youtube_<日期8位>`，落在**你运行命令时所在的文件夹**下；
- 想自定义可加 `--output-dir .\<自定义名>`，例如 `--output-dir .\xiyouji_1986_run1`；
- 换文件夹不会丢数据，但 **`--resume` 续跑必须在同一个输出目录下**才生效；
- 一次调研一个目录，旧目录只读留存，不做覆盖。

## 七、参考配置：西游记（1986 央视版电视剧）

以下是可直接套用的参考示例。**本轮只作参考，未写入 `pachong.py`**；实际使用时把这段加进 `TOPICS` 字典。

```python
"xiyouji1986": Topic(
    slug="xiyouji1986",
    title="1986版央视电视剧《西游记》海外评论",
    published_after="2024-01-01T00:00:00Z",
    language_queries={
        "zh": ["西游记 1986 影评", "央视西游记 解析", "86版西游记 反应", "西游记 观后感"],
        "en": [
            "Journey to the West 1986 review",
            "Journey to the West 1986 reaction",
            "Monkey King 1986 series review",
            "Journey to the West analysis",
        ],
    },
    inclusion_terms={
        "zh": ("影评", "影評", "评价", "評價", "解析", "观后感", "觀後感", "反应", "反應", "解说", "解說"),
        "en": ("review", "reaction", "analysis", "ending explained", "thoughts", "explained", "recap"),
    },
    # 别名务必齐全，否则候选会被误杀
    subject_terms=(
        "西游记", "西遊記", "央视西游记", "86版西游记", "1986版西游记",
        "journey to the west", "monkey king", "xi you ji",
    ),
    per_language=15,
),
```

**该主题必须注意的排除项（添加到主题级排除逻辑）：**

- 《黑神话：悟空》/ `Black Myth: Wukong` —— 游戏，热度极高但**不是**本主题要调研的电视剧，会严重污染数据；
- 其他西游衍生动画、电影（如《西游降魔篇》《大圣归来》《西游伏妖篇》）与游戏实况；
- 原著小说讲解、有声书、动画版（1999 央视动画版如需区分也应排除）。

> 注意：`pachong.py` 现有的 `NEZHA2_EXCLUSION_TERMS` 是针对哪吒2的硬编码排除。
> 新增主题若也需要硬排除（如上面的黑神话），需参照该写法在 `matches_eligibility` 中加一条主题级排除判断。
